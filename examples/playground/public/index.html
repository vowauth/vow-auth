3. Step-up and freshness

In a session row below press Enable 2FA: the simulated authenticator shows the code 424242. The next sign-in of that person then stops with step-up-required and asks for the code. A session also remembers which factors were passed and how long ago: Needs authenticator and Recent (30 s) are two sensitive actions that check it.

4. Agents (delegation)

Press Delegate agent in a session row. The agent gets its own token, which is never accepted as a person (try As session). What it may do is kept by the application (may write), not in the token. A delegation tied to the session dies with it; a free one survives sign-out until its delegation, the agent or the person is revoked.
